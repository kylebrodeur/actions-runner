# reference/

Reference material for re-use (adapt paths per repo). These carry no kit
code.

The kit's design laws were measured in real multi-month pipeline
operation. This kit carries the LAWS, not their history: the laws are in
`SYSTEM.md`, and the runner that enforces them is in `runner/`.

A reference implementation of the same shape belongs here, adapted so it
carries no other product's internals, no other product's names, and no
one else's decisions. The laws a consumer copies are the ones in
`SYSTEM.md`; this directory is where a worked example of them lives.
